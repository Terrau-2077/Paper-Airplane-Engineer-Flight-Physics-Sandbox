# 纸飞机工程师 Paper Plane Engineer

> 四个参数，一张纸，看懂波音 787 怎么飞。

一个基于薄翼理论的浏览器端飞行物理沙盒。调节机翼面积、重心位置、后掠角、上反角，观察纸飞机在真实气动力作用下的飞行表现。力矢量实时可视，物理公式透明可查。

## 快速开始

浏览器直接打开 `index.html`。无需安装，无需构建。

## 技术栈

Three.js（CDN） + 自研气动模型 + 原生 JS

## 目录

```
src/
├── core/           # 气动计算、飞行状态机
├── plane/          # 纸飞机 3D 模型、预设参数
├── simulation/     # 发射逻辑、任务评判
├── ui/             # 参数面板、HUD、结果页
└── visualization/  # 力矢量箭头
```

## 物理模型

- 升力 L = ½ρv²S·CL(α)
- 阻力 D = ½ρv²S·CD(α)
- 俯仰力矩 M = ½ρv²Sc·CM(α)
- 含失速模拟：攻角超过 15° 后 CL 骤降
